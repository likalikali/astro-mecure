# 写作提示草稿目录

本次依据 [秋月春风的公开归档目录](https://yukinoshitasherry.github.io/archives/) 中的 216 个不同文章链接，建立 216 篇独立写作草稿。采集时间：2026-11-07T00:28:20+08:00。

这些内容仅根据目录的文章标题识别主题，**不是读过全文后的摘要，更不是逐段转述**。每篇包含来源链接、主题提示、原创写作提纲和待填问题，没有搬入原文段落、图片或作者的个人经历。覆盖范围是本次归档页列出的链接，不声称包含未公开或未列入归档的文章。

## 如何使用

1. 在项目目录运行 `npm run studio`，打开本地编辑后台，选择草稿，搜索“写作草稿”或“待填写”。
2. 挑与你有关的主题，替换标题、正文、日期、分类和标签；不相关的选题可以删除。
3. 当前创建与修改时间是草稿生成时间，未设置首次上传时间 `date`。正式发布时再填写自己的首次上传时间。
4. 完成正文后移除提示文字，取消草稿状态再发布。当前全部为 `draft: true`，不会出现在网站文章列表、搜索或 RSS 中。

草稿放在 `src/content/blog/` 顶层，兼容现有编辑后台。提交到公开 GitHub 后文件可被查看，草稿状态不是隐私保护。原有文章未改动。来源学校名称仅作为参考标题保留，本站分类使用“课程笔记/课程研习”，不暗示你的就读经历。
