# 2026-10-29 工作日志

## 新增可视化前端文章发布管理系统 (Anriri Blog Studio)
- **后端服务**: `scripts/cms-server.js`（监听 `http://localhost:4322`），支持扫描与读写 `src/content/blog` 下的单文件（`.md`/`.mdx`）与独立目录（`index.md`/`index.mdx`）文章，严格兼容 `src/content/config.ts` 的 Zod Schema（未加引号的日期格式、标签自动去重、密码访问控制 `access` 字段）。
- **前端界面**: `scripts/cms-ui/index.html`，提供文章搜索筛选、拖拽上传 `.md/.mdx` 导入、剪贴板粘贴/拖拽上传本地插图与封面图、已有分类/标签一键点选、双栏实时预览，以及 Git 状态看板、`npm run build` 构建预检与一键 Commit + Push 上线到 `suborbit.net`。
- **快捷启动入口**: `package.json` 新增 `npm run cms` / `npm run studio`，根目录新增双击启动脚本 `start-cms.bat`。
