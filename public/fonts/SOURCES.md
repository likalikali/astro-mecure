# Web font sources

- **KingHwa OldSong 1.001 / 京华老宋体**: supplied by the site owner as `京華老宋体_KingHwa_OldSong 1.001.ttf`.
- **Google Sans**: Regular, Medium, Bold and their italics from [hprobotic/Google-Sans-Font](https://github.com/hprobotic/Google-Sans-Font/tree/42c6b3e1bb33c4a9831adb3406c3b7eef47d737b). Upstream copyright and font name records are retained in the converted files.

The WOFF2 files are generated by `scripts/prepare-webfonts.py` using FontTools and Brotli. The Chinese font is split into one subset for current site text and disjoint fallback subsets covering every remaining mapped character. CSS `unicode-range` declarations let browsers request only the needed subsets. Newly written articles do not require rebuilding the font assets.

To regenerate, install `fonttools` and `brotli`, then run:

```sh
python scripts/prepare-webfonts.py --chinese /path/to/KingHwa-OldSong.ttf --google-dir /path/to/google-sans
```

Normal site builds use the committed WOFF2 files and do not need Python or the original fonts. Generated filenames include content hashes for cache invalidation.
